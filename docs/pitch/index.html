No. 08 Cara kerja · how it is built

Arithmetic says no first. PayPal says yes last.

Jaminan · PayPal AI Hackathonv0.0.0-dev · 2a0ce13 · 08 / 11
Two phones talk to a FastAPI service on Vercel. Bad frames are rejected by arithmetic before any model call. Qwen answers narrow questions; decide_claim and the tariff decide; the state machine calls PayPal through a hand-written client and stamps only on PayPal's read-back. Webhooks are checked with PayPal's signature call and stored with the result.
